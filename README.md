# Darak Home Assistant add-ons

Home Assistant add-on repository for **Darak Agent**, the secure remote-management
agent Darak installs on customer-owned Home Assistant OS boxes.

Add this repository in Home Assistant: **Settings → Add-ons → Add-on store → ⋮ →
Repositories** and enter `https://github.com/Darak-PS/darak-addons`.

The agent does nothing until a Darak technician enrolls the box with a one-time
bundle. Published automatically from Darak's main branch; do not edit by hand.
